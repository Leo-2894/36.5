# 36.5

Windows 10/11 64비트용 카드 대전 게임입니다.

- [게임 실행본 ZIP](https://github.com/Leo-2894/36.5/releases/download/v1.6.7/36.5-v1.6.7-Windows.zip)을 모두 풀고 `36.5.exe`를 실행합니다.
- GitHub에서 **Code → Download ZIP**으로 저장소를 받았다면 압축을 모두 풀고 최상위의 `Run-36.5.cmd`를 실행합니다. 첫 실행에 동봉된 실행 파일을 로컬 폴더에 풉니다.
- Git LFS로 클론했다면 `36.5/36.5.exe`를 바로 실행할 수 있습니다.

EXE와 같은 폴더의 DLL, `resources`, `locales`를 함께 보관하세요.
